## 3. Working for the two figures that did not reproduce

The approval's grid and mine agree on both readings that keep the kill phase's first roll at +2 s,
and differ only where that offset is 0:

| Convention | Approval | Mine |
|---|---|---|
| phases t=5, kill +2 | 0.6148 | **0.6148** ✓ |
| phases t=0, kill +2 | 0.4389 | **0.4389** ✓ |
| phases t=5, kill +0 | 0.5443 | 0.4919 |
| phases t=0, kill +0 | 0.3847 | 0.3511 |

My kill-phase roll count is `rolls = 0 if rem < offset else (rem − offset) // 2 + 1`, so at
`offset = 0` and `rem = 25` I take **13** rolls (t = 0, 2, …, 24). Reproducing the approval's
0.5443 requires **12** — one fewer — which is what you get if the roll at t=0 of the kill phase is
*not* counted, i.e. if "first roll at +0" is read as "the phase begins at t=0 but its first roll is
still one interval in". That is the same convention as the +2 column, which is why those two
columns agree and these two do not.

Both are rejected readings, so nothing downstream depends on which is right. Recorded for the
record only.

episodes gives a very weak gradient regardless of what the probe does. v1.1 should inherit that
reasoning rather than the number.
