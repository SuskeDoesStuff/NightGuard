## 3. Decisions taken in planning

| Decision | Resolution |
|---|---|
| Jam bits: append or insert | **Inserted into the office block**, taking the observation to 100 dims and shifting every later block by two. Jam state is office state and §6.2 should read as one coherent block. Nothing depended on the old indices — v1.0 is the first version with an observation — so this was the last moment it was free |
| `Oracle`'s SPRINTER slot | **Stage, normalised.** A constant would report a zero gap for the entity whose hidden state matters most; an `armed` flag is exactly `stage == stages_to_arm` and could never disagree with the value beside it |
| `ticks_since_observed` when never observed | **1.0**, maximally stale. 0.0 collides with "seen this instant" and would make staleness jump upward on the first sighting |
| Belief at reset | **Seeded** from §3's deterministic start, staleness 0, read from **config not live state** — which is what keeps criterion 3 exact. The never-observed encoding is consequently unreachable under shipped configs but stays defined for v2.0's randomised starts |
